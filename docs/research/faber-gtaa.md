# ทดสอบกลยุทธ์ Faber GTAA Aggressive (Top 6) — ฉบับละเอียด

โมดูล: `lib/faber-gtaa/` · CLI: `npm run gtaa` · เทส: 33 รายการใน `lib/faber-gtaa/*.test.ts`

อ้างอิงแนวคิด: Mebane T. Faber, *A Quantitative Approach to Tactical Asset Allocation*
(2006, ปรับปรุง 2013) — เวอร์ชัน GTAA Aggressive Top 6 ตามที่โพสต์ต้นทางอธิบาย:
จักรวาล 13 สินทรัพย์ → ด่าน 1 ราคาปิดสิ้นเดือนต้องยืนเหนือ SMA 10 เดือนของตัวเอง
(ไม่ผ่าน → เงินสด/T-Bills) → ด่าน 2 จัดอันดับด้วย Momentum Score = ค่าเฉลี่ยผลตอบแทน
1/3/6/12 เดือน → ถือ Top 6 น้ำหนักเท่ากันตัวละ 1/6 → ทำซ้ำทุกสิ้นเดือน

## ข้อจำกัดของการทดสอบรอบนี้ (พูดตรง ๆ ก่อน)

**Session นี้ดึงข้อมูลตลาดจริงไม่ได้** — egress policy ของสภาพแวดล้อมโฮสต์ตอบ 403
ให้ทุกโฮสต์ข้อมูลการเงิน (Yahoo, Stooq — บันทึกไว้ใน proxy log) และ repo นี้
ไม่เขียนตัวเลขที่ตรวจสอบไม่ได้ลงรายงาน ดังนั้นสิ่งที่ "ทดสอบละเอียด" ได้จริงในรอบนี้คือ

1. **ความถูกต้องของกฎทุกข้อ** — พิสูจน์ด้วยยูนิตเทสกับอนุกรมที่คำตอบถูกต้องรู้ได้
   แบบปิดรูป (closed form) และ golden test ที่ตรึงกับตารางสัญญาณเดือนกันยายน
   ในโพสต์ต้นทางแบบตัวต่อตัว
2. **พฤติกรรมเชิงระบบของกลยุทธ์** — รันบนตลาดสังเคราะห์แบบกำหนด seed
   (ติดป้าย SYNTHETIC ทุกที่ที่แสดงผล) ที่เขียนสคริปต์ regime ไว้: ตลาดกระทิงยาว,
   วิกฤตทรง 2008 (หุ้น −45..55% ขณะพันธบัตร/ทองบวก), ช่วง whipsaw, และ
   hard-asset boom — เพื่อยืนยันว่าโค้ดทุก path ทำงานตามที่กฎสัญญา
3. **เครื่องมือรันกับข้อมูลจริง** — `npm run gtaa -- fetch` บนเครื่องที่ต่อเน็ตปกติ
   แล้ว `npm run gtaa -- run` ได้รายงานฉบับเดียวกันกับข้อมูลจริงทันที

ตัวเลขจากตลาดสังเคราะห์ **ไม่ใช่** หลักฐานว่ากลยุทธ์ทำเงินได้จริง — มันเป็นหลักฐานว่า
*กลไก* ทำงานตามสเปก (ตัดขาดทุนเมื่อหลุดเทรนด์, หมุนเข้าสินทรัพย์ที่แรง, พักเงินสด)

## สิ่งที่เทสพิสูจน์แล้ว (33 รายการ, เขียว 100%)

### กฎพื้นฐาน — เทียบคำตอบปิดรูป
- `sma`: ค่าเฉลี่ย 10 ค่าท้ายตรงสูตร, ปฏิเสธหน้าต่างที่ข้อมูลไม่ครบ/มี NaN (ไม่เดา)
- `kMonthReturn` ของอนุกรมโตคงที่ g ต่อเดือน = (1+g)^k − 1 เป๊ะถึงทศนิยมที่ 10
- `momentumScore` = ค่าเฉลี่ยเลขคณิตของ 4 lookback และเป็น **null จนกว่าครบ 12 เดือน**
  — คะแนนอุ่นเครื่องครึ่ง ๆ จะเอียงเข้าหาเดือนล่าสุดโดยเงียบ ๆ เราจึงห้ามผลิตมัน

### Golden test: ตารางเดือนกันยายนจากโพสต์
สร้างอนุกรมที่บังคับให้คะแนนออกมาเท่าตารางทุกตัว (DBC 19.59% … IEF −0.69%) แล้วยืนยันว่า:
- คะแนนตรงทั้ง 13 ตัว, บอนด์ 4 ตัว (TLT/LQD/IGOV/IEF) FAIL → เงินสด
- Top 6 = **DBC, VTV, GLD, EEM, VBR, MTUM** ตัวละ 16.67%, เงินสด 0%
- DWAS/EFA/VNQ ผ่านด่านแต่อันดับ 7-9 → ตัวสำรอง ไม่ได้เงิน — ตรงกับโพสต์ทุกบรรทัด

### ขอบกฎที่มักพลาดกัน
- ผ่านด่านน้อยกว่า 6 ตัว → ช่องที่เหลือ**นอนเงินสด ไม่เกลี่ยเพิ่ม**ให้ตัวที่รอด
  (เงินสดตรงนี้แหละคือ risk management ของเปเปอร์)
- สินทรัพย์ที่ประวัติไม่ครบ (เพิ่งเข้าตลาด) = ไม่มีสิทธิ์ ไม่ใช่คะแนนศูนย์
- คะแนนเท่ากัน → เรียงตามตัวอักษร: รันซ้ำร้อยครั้งได้พอร์ตเดียวกัน
- **filterThenRank vs rankThenFilter**: โพสต์ใช้ "กรองก่อนแล้วค่อยจัดอันดับ" แต่เปเปอร์
  อ่านได้อีกแบบคือ "จัดอันดับทั้ง 13 ก่อน แล้วช่องไหนหลุด SMA ช่องนั้นไปเงินสด"
  สองแบบต่างกันจริงเมื่อสินทรัพย์โมเมนตัมอันดับ 1 เพิ่งหลุดเทรนด์ (เทสสร้างเคสนี้ให้ดู:
  แบบแรกยกช่องให้ตัวถัดไป แบบหลังพักช่องนั้นเป็นเงินสด) — engine รองรับทั้งคู่,
  ค่าเริ่มต้นตามโพสต์

### Backtest loop
- **ไม่มี look-ahead**: สัญญาณสิ้นเดือน t ถือครองเดือน t+1 — พิสูจน์ด้วยอนุกรม 1%/เดือน
  ที่ equity ต้องเท่ากับ 1.01^n เป๊ะ (คลาดเคลื่อนหนึ่ง off-by-one ก็พังทศนิยมที่สิบ)
- **ด่าน SMA ทำงานจริงตอนวิกฤต**: ขึ้น 16 เดือนแล้วดิ่ง −12%/เดือน → ระบบออกไปเงินสด
  100% และอยู่นิ่งขณะราคาดิ่งต่อ; MaxDD ของกลยุทธ์ตื้นกว่า buy & hold มาก
  (−35% เทียบ −83%) แต่**ไม่ใช่ศูนย์** — ขากรรไกรแรกก่อน SMA ตัดยังไงก็โดน
- **ต้นทุนการเทรด**: หัก costBps × มูลค่าซื้อขาย (Σ|Δw|) ตรงเดือนที่เทรด — เทสยืนยัน
  รายเดือนว่า paid = free − turnover×cost ทุกเดือน และรายงาน cost drag สะสม
- **สถิติ**: MaxDD/underwater/win rate ตรวจกับเส้นทางที่คิดมือได้; Sharpe/Sortino ใช้
  **ผลตอบแทนส่วนเกินเหนือเงินสดจริง** (ไม่ใช่ศูนย์ลอย ๆ) — เทสยืนยันว่าเงินสดแพงขึ้น
  ทำให้ Sharpe ลด; ปีแรกหลัง warm-up เป็นปีไม่เต็ม รายงานตามจริง

### ระบบข้อมูล
- Resample รายวัน→สิ้นเดือน ใช้ราคาวันทำการสุดท้าย (print เดียวกับที่กฎอ่าน)
- Stooq ไม่มีคอลัมน์ adjusted → ใช้ close แทนพร้อม**คำเตือนดัง ๆ**: โมเมนตัมของ
  สินทรัพย์จ่ายยีลด์สูง (บอนด์, REITs) จะอ่านต่ำกว่าจริง — Yahoo adjclose คือค่าเริ่มต้น
- Panel เดียวกันทุกตัว เดือนก่อน inception เป็น NaN (= ไม่มีสิทธิ์) ไม่ใช่ศูนย์

## ข้อควรระวังก่อนใช้เงินจริง (จากการอ่านกฎอย่างละเอียด)

1. **ETF inception จำกัดประวัติจริง**: MTUM เกิด 2013-04 (ตัวช้าสุดใน 13 ตัว) + warm-up
   13 เดือน → backtest ด้วย ETF ชุดนี้ครบจักรวาลเริ่มได้ราว **กลางปี 2014** เท่านั้น
   ผลปี 1973–2012 ในเปเปอร์มาจากดัชนี ไม่ใช่ ETF — คนละต้นทุน คนละ tracking
2. **Turnover ~40%/เดือนของ Top 6 ไม่ฟรี**: ที่ 10bps กินไป ~0.5%/ปี ยังไม่รวม
   spread/slippage/ภาษี — ตัวเลข backtest ใด ๆ ที่ไม่หักต้นทุนคือเพดาน ไม่ใช่ค่าคาด
3. **SMA บนราคา vs total return**: ชาร์ตปรับปันผล (อย่างในภาพ TradingView) กับราคาดิบ
   ให้สัญญาณต่างกันตรงจุดที่ราคาคาบเส้นพอดี — engine ตั้งได้ทั้งคู่ (`--sma-on`)
   ระบุให้ชัดว่ารันแบบไหนแล้วอย่าสลับไปมา
4. **จังหวะสัญญาณ**: กฎอ่าน "ราคาปิดวันทำการสุดท้ายของเดือน" — ถ้าคำนวณกลางเดือน
   แล้วเทรดเลย นั่นคือกลยุทธ์อีกตัวหนึ่งที่ยังไม่ถูกทดสอบ
5. **เงินสดต้องเป็นเงินสดจริง**: ช่องที่ว่างเพราะสอบตกให้นอน T-Bills — การเกลี่ยน้ำหนัก
   เพิ่มให้ตัวที่เหลือคือการเพิ่ม concentration ตรงจังหวะที่ระบบกำลังบอกให้ลดความเสี่ยง

## วิธีรันกับข้อมูลจริง (บนเครื่องคุณ)

```bash
npm run gtaa -- fetch --dir data/gtaa      # ดึง Yahoo (adjclose) / fallback Stooq
npm run gtaa -- run   --dir data/gtaa --cost 10
npm run gtaa -- sensitivity --dir data/gtaa
npm run gtaa -- demo --seed 42             # ตลาดสังเคราะห์ ไม่ต้องใช้เน็ต
```

รายงานที่ได้: CAGR / vol / Sharpe / Sortino / MaxDD / underwater / win rate / turnover /
cost drag, ตารางรายปีเทียบ SPY, และ**ตารางสัญญาณเดือนล่าสุด**หน้าตาเดียวกับในโพสต์
(rank / score / PASS / FAIL→cash / weight) สำหรับจัดพอร์ตเดือนหน้า
